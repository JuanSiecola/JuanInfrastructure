# Homelab de Infraestructura y Redes by Juane

Portfolio técnico documentando un laboratorio de red simulada: firewall, routing inter-VLAN, segmentación, monitoreo y servicios en cloud, construido y documentado.

**Sitio publicado:** https://juansiecola.github.io/JuanInfraestructure/

## Stack

- **Lab de red** (GNS3 sobre Proxmox): pfSense, VyOS, Cisco IOSvL2
- **Servicios always-on** (Oracle Cloud, Docker Compose): Prometheus, Grafana, snmp_exporter, Uptime Kuma, NetBox, Nginx Proxy Manager
- **Conectividad**: Tailscale
- **Sitio**: MkDocs Material, deploy automático vía GitHub Actions
